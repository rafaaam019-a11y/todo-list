## ✨ Sobre o projeto

Esquecer tarefas é fácil. Organizá-las não precisa ser difícil.

O **Todo** nasceu como um projeto de estudo para praticar React na prática: componentes, estado, hooks e um fluxo de desenvolvimento moderno com Vite. O resultado é um app leve que abre rápido e é fácil de entender.

## 🚀 Funcionalidades

- 📝 Adicionar novas tarefas
- ✔️ Marcar tarefas como concluídas
- 🗑️ Remover tarefas que não precisa mais
- ⚡ Interface rápida, com atualização instantânea durante o desenvolvimento (HMR)

> 💡 *Ajuste esta lista conforme as funcionalidades que o seu app realmente tem.*

## 📦 Como rodar na sua máquina

**Pré-requisitos:** [Node.js](https://nodejs.org) na versão 20.19 ou superior (ou 22.12+).

```bash
# 1. Clone o repositório
git clone https://github.com/SEU-USUARIO/todo.git

# 2. Entre na pasta do projeto
cd todo

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
```

Depois, abra no navegador o endereço que aparecer no terminal (normalmente `http://localhost:5173`).

## 📜 Scripts disponíveis

| Comando | O que faz |
| --- | --- |
| `npm run dev` | Inicia o app em modo de desenvolvimento |
| `npm run build` | Gera a versão otimizada para produção na pasta `dist` |
| `npm run preview` | Mostra localmente como ficou a versão de produção |
| `npm run lint` | Analisa o código com o Oxlint |
